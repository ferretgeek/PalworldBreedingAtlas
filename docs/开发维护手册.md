# Palworld Breeding Atlas 开发维护手册

文档状态：2026-08-08。公开版只记录可复现的产品边界、工程约束和验证入口。

## 产品边界

这是一个本地优先、只读存档的 Palworld 配种工具：Tkinter 桌面端发现并解析本机存档，静态浏览器端提供配种规划、反向发现、图鉴与配方查询；同一套网页资源也可由 `server_publish.py` 在自托管环境中按需生成。

- 不上传存档、路径、库存、账号或日志；
- 不包含遥测、运行时更新器或生产数据库；
- 不分发 Oodle DLL，解析新版 Windows 存档时从用户合法安装的游戏或 Unreal Engine 中寻找兼容运行库；
- 服务端发布器只读 `Level.sav`，存档签名未变化时跳过生成。

## 目录

```text
src/pal_breed_helper/
  app.py                 桌面应用与任务编排
  save_parser.py         存档发现、稳定读取、解压与网页生成
  server_publish.py      自托管环境按需只读发布
  updater.py             永久离线兼容入口
  data/                  CharacterID 映射
  assets/                浏览器界面与数据资源
scripts/                 启动、验证、构建和可选真实存档烟测
tools/                   数据生成、校验与本机资源导入
tests/                   Python 与 JavaScript 测试
docs/                    当前维护、数据和版本文档
```

`build/`、`dist/`、`.runtime/`、`generated/` 和 `__pycache__/` 都是可重建的本地状态，不应提交。

## 数据流与不变量

```text
Level.sav ──只读稳定快照──> 当前世界库存
GlobalPalStorage.sav ──可选只读──> 跨界基因
两路独立结果 ──generation/cancel 校验──> 隔离网页包
```

- 默认图鉴严格为 287 条；隐藏 Boss、联动、重复与未完成单位不得混入普通池。
- 图鉴 key 必须保持字符串，例如 `1`、`38B`。
- 基础工作适性最大 8、系统强化上限 10，必须分别表达。
- 当前世界库存、跨界基因和未知单位不能混合计数。
- 跨界状态必须区分 `ok`、`missing`、`error`；读取失败要明确提示部分结果。
- 未知 CharacterID 必须显式报告，不能静默跳过。
- 后台任务只能先写 `.analysis-*`；只有当前 generation 可以发布，取消或失败必须清理。
- 不恢复远程 EXE 自更新，不新增运行时联网或遥测。

## 修改入口

- 数据：修改 `tools/update_game_data.py` 的受控输入并重新生成，不手改大型生成文件。
- 数据契约：`tools/validate_data.py`。
- 存档：先为最小结构或用户自备样本补测试，再改 `save_parser.py`。
- 求解器：保持核心逻辑可由 Node 独立测试。
- UI：延续一套深灰暗色与三套完整浅色主题，以及“选目标 → 设条件 → 生成路线”结构，并保留桌面、窄屏、键盘、空/错/忙/禁用状态。

## 运行与验证

```powershell
.\scripts\run.ps1
.\scripts\verify.ps1
.\scripts\build.ps1
```

真实存档烟测由使用者在本机显式传入，不把绝对路径或样本提交到仓库：

```powershell
$env:PALWORLD_SAVE = 'C:\path\to\Level.sav'
.\scripts\smoke-real-save.ps1
```

交付顺序：自动门禁 → 可选真实存档 → 浏览器桌面/窄屏 → 桌面端扫描与取消 → 构建 → 更新文档。

## 已知边界

- CharacterID 提取不是完整通用 GVAS 对象模型；
- Xbox / Game Pass 原生 WGS 只检测，需先导出标准 `Level.sav`；
- 游戏版本、跨界数组或压缩格式变化后需要用户自备样本回归；
- 游戏图像及相关素材权利归原权利方，不在 MIT 代码许可证范围内。

## 接手顺序

阅读 `AGENTS.md`、`README.md`、本文和 `docs/数据来源与更新.md`，再运行 `scripts/verify.ps1`。定位调用链与测试后做最小改动，并同步 `docs/版本记录.md`。
