# 版本记录 / Changelog

## 3.5.1 — 待发布 / Unreleased

- 新增“森语”完整浅色主题，使界面具备一套深灰暗色与三套不同气质的浅色主题。
- 新增 SVG、ICO、Apple Touch Icon、Web App Manifest 与 192/512 PNG 品牌图标。
- 修复生成网页未复制顶层 PNG 资产的问题，并新增主题、图标和 Manifest 回归测试。
- 补齐双部署运维、贡献与标准变更入口；明确自托管库存页面必须置于 HTTPS 与认证反向代理之后。
- 为存档读取与每层 zlib 解压增加解析前字节预算；库存 JSON 增加文件、记录与个体上限；服务器状态不再持久化异常中的本机路径。

## 3.5.0 — 2026-07-20

- 当前世界现役帕鲁与账号级跨界基因严格分离；跨界默认不参与规划。
- 已出售或删除的帕鲁不再被历史记录、旧槽位或空槽重新计入。
- 修复旧 `PlZ 0x32` 双层 zlib 存档的中间层长度校验，同时兼容新 Oodle 与旧 zlib 存档。
- 新增 `server_publish.py`：可在自托管环境中按存档签名只读生成网页，不持续扫描，也不修改存档。
- 自动门禁覆盖 Python、数据契约和 JavaScript 求解器；数据保持 287 条正式图鉴与 41,329 条配种记录。

## 3.4.0 — 视觉与启动器整合

- 浏览器三页和桌面启动器统一为深幻夜、鎏金主操作、青色信息与帕鲁紫点缀的视觉语言。
- 强化目标、条件和结果的信息层次，补齐移动端、键盘、减少动态效果与异常状态。

## 3.3.x — 库存与任务可靠性

- 本世界库存、跨界基因和未知单位保持独立状态。
- 引入结果条件签名、规划缓存、分批渲染和滚动位置恢复。
- 桌面端使用 generation/cancel 隔离任务，只有当前任务可以发布网页包。

## 3.2.x — 信息架构

- 建立“选目标 → 设条件 → 生成路线”主流程。
- 加入属性、工作、战斗定位、拥有状态、补充数量、反向发现与高级筛选。

## 3.0.0 — 可维护重建

- 重建为 Python 源码、静态浏览器应用、可重复数据生成器和自动测试。
- 固定 Palworld 1.0 数据来源、输入哈希、过滤规则和 provenance。
- 移除远程 EXE 自更新，确立本地优先、只读存档和无遥测边界。
